Noch kein Modul geladen. Bewertungen sind persönliche Angaben, keine automatische Freigabe.

      Nur tatsächlich bewertete Punkte werden exportiert. JSON unter reviews/results/ ablegen, dann python3 reviews/manage.py summary ausführen und den Beitrag committen bzw. per Pull Request einreichen. Der Browser schreibt nicht direkt in das Repository.
      
Die automatisch erzeugte Übersicht zählt unabhängige E-Mail-Angaben. Namen und Befugnisse werden im Beitragsreview geprüft. Abdeckung ersetzt weder technische Tests noch Releaseabnahmen.
